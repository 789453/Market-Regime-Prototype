# 中期大阶段：全维信息提取、原型发现比较与基础多空策略

更新：2026-09-28。本文件将《改进提示词1/2》与后续要求合并为**一个连续交付阶段**。阶段终点不是写完若干小任务，而是：全量双频候选字段进入形态表示；至少三种有实质差异的原型/距离设计在同一前向协议下比较；形成可重跑的原型卡片、信号生命周期、真实买入持有外部比较、可视化和阴性记录。若某方案无优势，完成有边界的阴性研究，继续换机制或表达，不把阈值单点改善当成阶段成功。

**阶段状态：已完成此轮交付。** 六种方法、九折前向、原型和策略全量结果见[综合报告](../reports/crypto/04_full_pattern_stage.md)。完成研究阶段不等于已经认证可交易策略；2026 仍为冻结终段。

## 1. 研究问题与继承

旧项目最值得保留的是**局部条件分布、机制先行、收缩、匹配随机对照、可靠度与经济价值分离、事件生命周期和严格可用时间**，以及研究账本。七组各八字段、5m/15m 共 112 个当前字段已经建成；它们是形态的感知层，不是 112 个独立 alpha。旧 Ridge 预测是直接预测对照，不能回答原型为何出现或为何开仓。有限原型库才是策略本体：`语义轨迹 → 原型相似度 → 历史条件结果与不确定性 → 多/空/观望/退出`。

一个原型同时有**几何身份**和**结果身份**。几何身份是机制名称、历史轨迹代表、组/字段权重、允许范围与否决条件；结果身份是各持仓期方向收益、上下尾风险、时间/币种覆盖、相似度邻域、高原和前向稳定性。几何密度高但没有结果分离，仅能称为市场状态。

## 2. 几乎全量字段如何进入原型，而不使维度灾难吞没机制

保留 112 个字段，不用只挑 7–13 个输入。另在每个合约的历史状态上加 1h、4h 的组代表滞后水平/变化，使“先压缩再释放”“冲击后的回收”真的含顺序。全量字段统一按**每折训练窗**的经验分位映射到 `[0,1]`；后验期间只 `transform`，无未来分布信息。缺失、常数、离散时间字段保留质量标签，不能凭空插入未来值。

对原型 `k`、组 `g`、字段 `j`，距离定义为

`D_{k,g}(t)=Σ_j a_{k,g,j} ρ(|u_{t,j}−c_{k,j}|; h_{k,j}) / Σ_j a_{k,g,j}`；

`D_k(t)=Σ_g w_{k,g}D_{k,g}(t)/Σ_g w_{k,g}`，`S_k(t)=exp(−D_k(t)/τ)`。

`u` 是训练窗分位，`c` 是形态中心或 medoid，`h` 是训练期同类轨迹的稳健半宽，`ρ` 在核心区低曲率、越界后加速惩罚。`a` 对全字段保持正下限，但由**原型对训练背景的对比度**和组内相关冗余决定：高频重复量不许重复投票，弱但不同的字段仍有发言权。组间 `w` 先由经济机制给出非负先验，再使用训练窗前后两段都为正的条件分离证据作有限幅度、强收缩的动态调整。时段组弱权重且独立审计；时间周期变量不能把午夜附近误作相距很远。

本阶段先把全量信息用于**几何度量**，不强迫每个原型以全部维度等权解释。无关字段的低权重是可解释的选择，不是预先删除。之后报告有效字段数、组贡献和极端匹配样本，检查中心是否只因高维平均而接近所有状态。

## 3. 原型的来源与比较矩阵

**机制种子 + 历史归纳**为主线：趋势延续、压缩释放、冲击回收、低效率区间回归各分多/空。种子仅规定少数必要语义与方向，训练窗按种子相似度取候选轨迹；从候选中学习全 112 维稳健中心、宽度与时间路径，绝不从验证期未来收益移动中心。对压缩释放，必须显式要求过去波动低、当前波动抬升；若仅有波动加速则改称扩张，不能冒名。

同一原型家族在相同折、相同标签与事件间隔下比较：

| 版本 | 表示/距离 | 检验的具体假说 |
|---|---|---|
| V0 sparse | 旧六种少数字段机制种子 | 少量强语义是否足够 |
| V1 equal | 全字段中心、等组权 | 更多信息是否直接增加识别力 |
| V1 redundancy | 全字段中心、组内对比度/冗余权 | 去重复投票是否改善 |
| V1 dynamic | 上版 + 仅训练期可靠度收缩组权 | 动态权重是否有稳定前向增量 |
| V1 semantic gated | 核心机制相似度约束 + 全维动态相似度 | 全维平均是否稀释必要机制 |
| V1 cosine | 相同字段的普通向量余弦 | 数学上的近是否等于经济上的近 |

这些是内部设计消融，不是外部投资 benchmark。未来可加入轨迹 medoid、无监督 motif 或监督 shapelet；只有本阶段证明普通全维表示的具体问题之后才增加模型容量。先观察原型形状和失败样本，再决定是否用 CNN/MLP 学编码；任何压缩后的距离必须在未来条件分布上胜过简单语义距离。

## 4. 前向协议与统计层级

仅使用 2023–25 为开发区；2026 的价格、收益、特征继续不读取。按 UTC 同时切所有合约：过去约 365 日拟合分位参考、原型、权重和阈值，标签可用时间早于测试折开始；未来约 90 日冻结测试，循环到 2025 年底。每个原型在训练期固定一个高相似触发分位，并同时报告邻域 99/99.5/99.75%。一合约同一原型的触发至少间隔 4h；跨币同一行情由日/周共同块处理，不把事件行数当作独立样本量。

分别报告：折、年、合约、多空、机制、相似度档、4h 条件毛收益、上下侧风险、覆盖、方向冲突、中心与权重漂移。用 7 天日期块给不确定区间，并加保持币种/月/时段/波动及跨币时间簇的对照；大量原型/距离/阈值尝试记成同一家族。2025 年旧实验已看过，所以此协议是开发前向，仍不是独立发布认证。2026 必须在研究方案冻结后一次性终段评估。

## 5. 从原型到策略与研究边界

先做两层输出。**基础信号**保存各原型相似度、历史收缩条件期望、置信度和冲突；高相似但无正向历史证据则不交易。**策略生命周期**在下一可用 5m 开盘调整：进入阈值高于退出阈值；相反原型证据抵消或清仓；最大持有、冷却及标的上限明确。并行检验固定 4h 事件持有、状态滞回持有与 99.75% 稀疏阈值，不把某一退出规则的偶然收益转嫁给原型。波动缩放只作独立的仓位消融，不与原型表示调参混合。

外部投资比较只用同起点、初始等额且不再平衡的 12 币买入持有。成本、滑点和资金费率尚无可证实口径，报告 0/4/10bp 每边的**情景**作为执行压力检查；基础形态的几何与预测分离仍是研究重心。没有足够可靠原型时，策略层保持空仓并报告阴性，绝不通过回看 2026 选模型。
