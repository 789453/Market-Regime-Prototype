## 1. 形态的数学身份：先把神秘感去掉

去掉一切图形学的修辞，形态识别就是**局部非参数条件期望估计**：

\[
\hat\mu_A = \hat{\mathbb{E}}\big[\,\tilde r_{t+h} \;\big|\; \mathbf{x}_t \in A\,\big],\qquad A \subset \mathbb{R}^d
\]

对比：因子模型是**全局线性投影**（用全部样本估一组系数），形态是**局部指示函数估计**（只用落进 \(A\) 的样本估一个数）。

由此得到形态方法的全部优点与全部缺点：

| | |
|---|---|
| **优点** | 抗噪（只在少数时刻下注）、天然非线性、天然内嵌 regime 条件、完全可解释、可做分叉逻辑（同一初始事件按后续演化分成截然相反的两支） |
| **缺点** | **样本被切碎**。一个"精确"的形态半年触发 30 次，条件均值标准误 \(\sigma/\sqrt{30} = 0.18\sigma\)，而你要找的效应是 \(0.10\sigma\) 量级 —— 统计上零信息量 |

**因此本项目对形态的第一硬约束是：宁可粗糙但触发频繁，不要精细但触发稀少。**具体门槛：池化触发次数 ≥ 150，Tier A 三品种各 ≥ 25。任何低于此的形态定义必须放宽，而不是保留。

## 2. 形态设计的元原则：从"流"出发，不从"图"出发

经典形态（头肩、三角、旗形）是公开的、被全世界实时扫描的。在这些形态上"抢先"不现实。形态之所以能有效，是因为它是**结构性资金流的可观测印记**。这些流有三类：

**（1）强制性流（forced flow）—— 最可靠。**不基于观点，由规则或风控强制触发，因此方向与时点可预测：
- 止损簇集：止损单在结构性价位（前日高低、开盘区间边界、整数关口、近期摆动点）密集堆积。突破触发级联；但若成交量未跟上且价格迅速收回，说明只是流动性扫单而非真实重定价
- 期权对冲流：做市商在正 gamma 环境下低买高卖（压制波动、增强回归），负 gamma 下反向（放大趋势）。0DTE 的普及使这个效应在美股日内尺度上极强，且高度时段化
- 被动与再平衡流：MOC 不平衡、月末/季末再平衡、指数调整、期货展期
- 保证金追缴：大跌后次日早盘的被动减仓

**（2）执行算法的可预测轨迹。**TWAP/VWAP 把大单摊到时间上，产生日内收益自相关。印记是：温和的、成交量均匀的、单向漂移。执行结束后有临时冲击的衰减（部分回吐）。**VWAP 附近的均值回归**是最稳定的日内结构之一，因为大量执行以 VWAP 为基准 —— 这是制度事实，不是统计巧合。

**（3）信息到达与注意力的时间结构。**数据发布后的漂移、跨市场 lead-lag、会话开盘的信息重定价。

> **操作要求**：`HYPOTHESES.md` 中每个假设必须先写清楚"此刻存在什么被迫的、可预测的资金流"，再反推它会在价量上留下什么印记，最后才编码。这个顺序不能反。它是本项目最有效的搜索空间削减手段 —— 把"无穷多种图形"压缩到"十几种流机制"，直接缓解多重检验问题。

## 3. 尺度不变性（形态定义的硬约束）

由于必须跨品种、跨时段池化（否则样本不够），形态**只能用无量纲量定义**。

**禁止**：绝对点数、绝对成交量、固定百分比阈值。
**允许**：

| 类型 | 例子 |
|---|---|
| 波动率标准化量 | \(\tilde r = r/\hat\sigma\)；突破幅度 \(= (P - H_{\text{prev}})/\hat\sigma\) |
| 经验分位 | 当前 range 在过去 60 bar 的分位 |
| 比值 | 回撤幅度/推进幅度；回撤时长/推进时长；量比 |
| 序数关系 | \(H_2 > H_1\)、\(L_2 > L_1\) |
| 形状归一化后的相关 | 去趋势 + z-score 后与模板的相关系数 |

这条约束不是妥协，而是收益：尺度不变的形态经济含义更本质，也更可能在商品/加密上迁移。

## 4. 基础设施：结构引擎与符号化

### 4.1 ZigZag 摆动引擎（`structure.py`）

把连续价格路径离散成摆动序列。**阈值必须用波动率定义**，否则跨品种不可比：

\[
\theta_t = \kappa \cdot \hat\sigma_t \cdot \sqrt{n_{\text{ref}}},\qquad \kappa \in [1.5, 3.0],\ n_{\text{ref}} = 12
\]

算法（在线、无前视）：
```
维护 last_pivot (价格, 时间, 类型)
维护 extreme (自 last_pivot 以来的极值)
对每个 bar:
    更新 extreme
    if 方向为上 and (extreme - close) > theta[t]:
        确认 extreme 为一个 peak pivot（确认时间 = 当前 bar，不是 extreme 所在 bar）
        方向翻转
    对称处理向下
```

> **前视陷阱**：pivot 的**发生时间**是 extreme 所在 bar，但**确认时间**是回撤达到阈值的那根 bar。所有下游使用必须以**确认时间**为准。写一个断言：`pivot.confirm_time >= pivot.event_time`，且检测器在 \(t\) 时刻只能看到 `confirm_time <= t` 的 pivot。这是形态类策略最常见的前视来源。

每个摆动 segment 记录属性（全部无量纲）：
```
direction          # +1 / -1
amp_sigma          # 幅度 / (sigma * sqrt(duration))
duration_bars      # 时长（bar 数）
vol_ratio_seg      # 该段平均成交量 / 前 N bar 平均成交量
er_seg             # 该段内的效率比
phase_start/end    # 起止时段
```

由此可构造结构特征：
- **结构类型**：最近 3 个 pivot 的高低关系 → `{HH-HL, LH-LL, HH-LL, LH-HL}`
- **回撤比**：\(\text{retrace} = |\text{回撤幅度}| / |\text{推进幅度}|\)，分档 `{浅 <0.4, 中 0.4–0.7, 深 >0.7}`
- **时间比**：回撤时长 / 推进时长。\(>1\) 表示回撤"拖沓"（弱势回撤，趋势延续概率高）
- **量能比**：回撤段均量 / 推进段均量。\(<1\) 表示无真实抛压

这四个维度能表达绝大部分经典形态，且**把 200 根 bar 压缩成十几个数**。降维即正则化 —— 这是抗过拟合的关键。

### 4.2 符号化与 back-off 平滑（探索工具）

把 \(\tilde r\) 离散成符号，形态 = 符号串。这是**唯一样本量天然充足**的形态编码方式，适合做大规模筛查。

**二维符号**：每个 5min bar 编码为 \((\text{收益档}, \text{形态档})\)
- 收益档：\(\tilde r\) 的 3 分位或 5 分位 → `{--, -, 0, +, ++}`
- 形态档：实体/全幅比 \(\frac{|c - o|}{h - l}\) 的 2–3 分位 → `{实体, 影线}`

> K 线的上下影线包含盘中的"拒绝"信息（价格到过那里但没留住），这是纯收益序列丢失的。加这一维通常显著提升判别力。

**back-off 平滑**（借自语言模型）：长模式向短模式收缩

\[
\hat\mu(\mathbf{s}_{1:L}) = \lambda_L\,\bar r(\mathbf{s}_{1:L}) + (1-\lambda_L)\,\hat\mu(\mathbf{s}_{2:L}),\qquad
\lambda_L = \frac{n(\mathbf{s}_{1:L})}{n(\mathbf{s}_{1:L}) + \nu}
\]

\(\nu\) 为收缩强度，取 \(\nu \approx 50\)。递归到长度 1。这让稀有模式自动向其后缀的估计靠拢，避免稀有模式的极端估计。

**用法定位**：符号化不是生产信号，是**探索器**。用它在 3-gram / 4-gram 上做全扫描，找出条件均值显著偏离的模式，然后**人工把发现的模式翻译成 4.1 节的结构语言**并写成一个有机制解释的检测器。直接把 n-gram 统计当信号会撞上严重的多重检验问题（\(5^4 \times 2^4 = 10000\) 个模式）。

### 4.3 模板匹配（仅作探索）

对 \(\log P\) 在窗口内做去趋势 + z-score 归一化，与模板库算相似度或做 k-shape 聚类。

**态度**：探索可以，生产要谨慎。欧氏/DTW 距离在高维下判别力衰减快，且把"形状"与"重要性"混为一谈 —— 两个形状相似的窗口，一个发生在关键位、一个发生在无人区。**用它发现你没想到的模式，然后翻译成结构语言。**

## 5. 检测器统一契约（`detectors/base.py`）

```python
class Detector(ABC):
    detector_id: str          # "D01"
    hypothesis_id: str        # "H-01"，必须在 HYPOTHESES.md 中存在
    params: dict              # 全部参数，含默认值
    param_grid: dict          # 用于稳定性扫描的网格
    default_horizon: int      # bar 数
    expected_sign: int        # +1 顺势 / -1 反转（先验，用于符号约束）
    required_context: list    # 需要的 context 变量名

    def detect(self, bars: pd.DataFrame, ctx: pd.DataFrame) -> pd.DataFrame:
        """返回契约见下。必须逐 bar 因果：t 时刻只能用 <= t 的信息。"""
```

输出契约：
```
root, timestamp,
direction   ∈ {-1, 0, +1}
magnitude   ∈ [0, 1]        # 触发强度，用于分档统计与仓位缩放
horizon     int             # 建议持有 bar 数
confidence  ∈ [0, 1]        # Stage 4 由分层收缩后验填入；Stage 3 先置 1.0
meta_*                      # 诊断用中间量
```

**强制的因果性测试**（每个检测器都要过）：
```python
def test_causality(detector):
    full = detector.detect(bars, ctx)
    for cut in [0.4, 0.6, 0.8]:
        n = int(len(bars) * cut)
        partial = detector.detect(bars[:n], ctx[:n])
        assert_frame_equal(partial, full[:n])   # 逐点相同
```
这一个测试能挡掉 90% 的前视 bug，包括那些藏在 `rolling().mean()` 的 `center=True`、`shift(-1)` 笔误、以及 ZigZag 确认时间里的。

## 6. 检测器库

以下 8 个是初始清单。**已根据数据事实 F2（HSI/HTI 仅夜盘）重新设计了 D06。**每个给出：机制、触发谓词、参数与网格、预期方向、预期状态、最小触发数。

### D01 · 流动性扫单反转（Liquidity Sweep Reversal）
- **机制**：止损簇集被触发但无真实重定价需求
- **触发**（做空版，做多对称）：
  1. 存在参考高点 \(H^{\text{ref}}\)：过去 \(N\) bar 的最高价，或当日会话开盘 30min 区间高点，或前一会话高点
  2. \(\max(\text{high}_{t-m:t}) - H^{\text{ref}} \ge \alpha \cdot \hat\sigma_t\)（有效突破）
  3. 突破段量比 \(< q_{\text{lo}}\)（无量能确认）
  4. \(t\) 时刻 \(\text{close}_t < H^{\text{ref}}\)（已收回）
- **参数**：\(N \in \{24,48,96\}\)，\(m \in \{2,3,4,6,8\}\)，\(\alpha \in \{0.2,0.3,0.4,0.5\}\)，\(q_{\text{lo}} \in \{1.0,1.2,1.5\}\)
- **方向**：\(-1\)（反向） · **horizon**：12–24 bar
- **gate**：低 ER、低-中 sigma_pct、vol 收缩、流动性正常
- **最小触发**：池化 200

### D02 · 量价确认突破（Volume-Confirmed Breakout）
- **机制**：真实重定价 + 止损级联的顺向延续
- **触发**：与 D01 条件 1–2 相同，但 3 改为量比 \(> q_{\text{hi}}\)，4 改为「\(m\) bar 内保持在 \(H^{\text{ref}}\) 上方，且回撤 < 突破幅度的 50%」
- **参数**：\(q_{\text{hi}} \in \{1.5,1.8,2.2,3.0\}\)，其余同 D01
- **方向**：\(+1\) · **horizon**：24–48 bar
- **gate**：高 ER、vol 扩张、高 liq_z

> **D01 与 D02 是同一初始事件的两个分支。**这正是形态优于因子的地方 —— 线性因子无法表达这种分叉。**实现上必须共享突破检测代码**，只在分支判据上分开，否则两者的定义会漂移，统计不可比。同时它们的触发集合必须互斥（用同一个 \(m\) 窗口判定），这样才能做一个干净的"给定突破，分支预测力"的联合检验。

### D03 · 弱势回撤延续（Lazy Pullback）
- **机制**：趋势中的回撤只是获利了结与流动性缺口，无真实反向流
- **触发**（基于 4.1 结构引擎）：
  1. 结构为 `HH-HL`（或 `LH-LL`）
  2. 回撤比 \(\in [0.3, 0.65]\)
  3. 时间比 \(> 1.2\)（回撤拖沓）
  4. 量能比 \(< 0.85\)（回撤无量）
  5. 价格在回撤低点附近企稳（最近 3 bar 未创新低）
- **参数**：\(\kappa\)（ZigZag 阈值）\(\in \{1.5,2.0,2.5,3.0\}\)，回撤比上下界，时间比阈值，量能比阈值
- **方向**：\(+1\)（顺趋势） · **horizon**：24–48 bar
- **gate**：高 ER、中波动
- **最小触发**：池化 150

### D04 · 波动压缩后的方向选择（Compression Break）
- **机制**：低波聚集后的波动扩张（波动率均值回复是强规律）+ gamma 环境翻转
- **触发**：
  1. `vol_ratio` \(< v_{\text{lo}}\)（如 0.7）持续 \(K\) bar
  2. 近 \(N\) bar 的 range 处于过去 \(M\) bar 的低分位（\(< 25\%\)）
  3. 首次向任一方向的有效突破：\(|\text{close}_t - \text{mid}| > \alpha\hat\sigma_t\)
- **方向**：突破方向 · **horizon**：24–48 bar
- **特殊价值**：触发条件是**二阶矩**的，而二阶矩你能估准（文档 01）。这是本清单中先验最强的一个。
- **gate**：低 sigma_pct、vol 由收缩转扩张

### D05 · 会话开盘的信息重定价（Session Open Repricing）
- **机制**：会话间累积的信息在开盘一次性释放；小幅重定价多为噪音/流动性（回补），大幅重定价多为真实信息（延续）
- **触发**：会话开盘后 \(k\) bar，计算
  \[
  z_{\text{open}} = \frac{\log(\text{close}_{\text{open}+k}) - \log(\text{close}_{\text{prev\_close}})}{\hat\sigma_{\text{overnight}}}
  \]
- **方向**：**非单调条件反应** —— \(|z| < 0.5\) → 反向（gap 回补）；\(|z| > 1.5\) → 顺向（延续）；中间 → 不下注
- **实现要点**：不要拟合一条线。直接把 \(z\) 分成 6–8 个分位桶，逐桶估条件均值，然后用 isotonic 或简单平滑得到映射。**这是本清单中唯一一个明确的非单调形态**，也是最能体现"形态 vs 因子"差异的例子。
- **适用**：ES/NQ/RTY 的 Globex 开盘与美股现货开盘（两个不同事件，分开统计）；HSI/HTI 的夜盘开盘（消化港股日盘收盘至今的信息，机制更强，因为跨越了整个港股日盘的信息真空）
- **最小触发**：每会话 1 次 × 130 会话 × 5 品种 = 650（充足）
- **注意**：这个检测器的样本量结构与其他完全不同（每会话 1 次，跨日近似独立，无重叠标签问题），因此它的 t 检验最可信。**建议作为第一个实现的检测器**，用来验证整条流水线。

### D06 · 跨市场同步 lead-lag（ES → HSI，已按 F2 重设计）
- **原设计失效**：F2 表明无港股日盘数据，"ES 隔夜 → HSI 开盘 gap"不存在
- **重设计机制**：HSI/HTI 夜盘与欧美盘完全重叠（HKT 17:00–03:00 = UTC 09:00–19:00）。夜盘流动性薄，价格发现主要由 ES 承担，HSI 存在**反应不足**（under-reaction）。设

  \[
  \varepsilon_t = \tilde r^{HSI}_{t-k:t} - \hat\beta \cdot \tilde r^{ES}_{t-k:t}
  \]

  其中 \(\hat\beta\) 用滚动窗口（扩展窗口，最小 20 会话）估计。\(\varepsilon_t\) 显著为负（HSI 涨得不够）→ 预期 HSI 补涨。
- **参数**：\(k \in \{1,2,3,6,12\}\)（由 C10 的交叉相关函数确定初值），\(\varepsilon\) 的触发分位 \(\in \{0.1, 0.15, 0.2\}\)
- **方向**：\(-\text{sign}(\varepsilon)\) · **horizon**：6–24 bar
- **现实提醒**：这个信号的最优 horizon 可能很短（分钟级），而 HSI 夜盘成本 2–4.5 bp。**大概率会在成本墙前失效。**若如此，如实记录 —— 这是一个有价值的阴性结论：它说明这条 lead-lag 已经被套利到成本边界。同时把 \(\varepsilon_t\) 保留为 context 变量（它是港股夜盘风险偏好的一个干净度量）。

### D07 · 日内 VWAP 引力与偏离（Session VWAP Reversion）
- **机制**：大量执行以 VWAP 为基准，形成价格引力；同时 VWAP 是"平均成本线"，偏离过大触发获利了结与逆向执行
- **实现**：数据集直接提供 `wap` 字段，会话内累计 VWAP
  \[
  \text{VWAP}_t = \frac{\sum_{i \le t} \text{wap}_i \cdot \text{volume}_i}{\sum_{i \le t}\text{volume}_i}
  \]
  （只累计 valid bar）
- **触发**：偏离度 \(d_t = \dfrac{\log P_t - \log \text{VWAP}_t}{\hat\sigma_t \sqrt{\text{bar\_in\_session}}}\)，配合 VWAP 自身斜率 \(\nabla\text{VWAP}\)
  - \(|d| > d_{\text{hi}}\) 且 \(|\nabla\text{VWAP}|\) 小（VWAP 平坦）→ 反向（回归）
  - \(|d| \in [d_{\text{lo}}, d_{\text{hi}}]\) 且 \(\nabla\text{VWAP}\) 同向 → 顺向（延续）
- **参数**：\(d_{\text{lo}} \in \{0.5,0.8\}\)，\(d_{\text{hi}} \in \{1.5,2.0,2.5\}\)，斜率窗口
- **gate**：`US_LUNCH` 时段回归性最强；vol 收缩时回归性最强
- **最小触发**：池化 300+（这是触发最频繁的检测器）

### D08 · 收盘前不平衡漂移（Close Imbalance Drift）
- **机制**：MOC 不平衡、日末风控调仓、被动基金现金流。这些流在美股收盘前 30–60 分钟高度集中且方向部分可预测（与当日累计收益相关：大涨日的再平衡卖压、大跌日的买盘）
- **触发**：进入 `US_CLOSE` phase，条件于
  - 当日累计标准化收益 \(z_{\text{day}}\) 的分位
  - 当日 RV 相对 HAR 预期的比值
  - `is_month_end` / `is_quarter_end`（再平衡强度）
- **方向**：由分位桶的条件统计确定，先验上预期与 \(z_{\text{day}}\) 弱反向
- **仅适用**：ES/NQ/RTY。HSI/HTI 夜盘无对应结构（夜盘尾段是流动性枯竭而非再平衡）
- **样本量**：130 会话 × 3 品种 = 390 次，且跨日近似独立。**可信度高，值得优先做。**

### 6.1 检测器实现顺序建议

## 7. 统计卡片（`stats/cards.py`）

每个检测器 × 每组参数，产出一张标准化卡片。**这是本项目最核心的产出物。**

### 7.1 卡片内容

**基础统计**
- 触发次数：总数、按 root、按 phase、按月份
- 触发间隔分布（检查是否簇集在少数几天 —— 若 80% 触发来自 10 个交易日，则名义样本量严重高估）
- 方向分布（多/空比例）

**效应量**（全部用标准化收益 `fwd_ret_z`）
- 条件均值 \(\hat\mu_h\) 及其 bootstrap 置信区间，\(h \in \{6,12,24,48,96\}\)
- **最优持有期曲线**：画 \(\hat\mu(h)\) vs \(h\)。这条曲线告诉你信息衰减速度，进而决定它在成本约束下的价值。一个在 \(h=6\) 达峰后迅速衰减的形态，扣成本后可能一文不值
- 条件夏普：\(\hat\mu_h / \hat\sigma(\text{fwd\_ret\_z}_h)\)，年化
- 胜率与赔率（盈亏比），以及 \(\text{胜率}\times\text{赔率}\) 的分解
- **扣成本后的条件均值**：\(\hat\mu_h \cdot \sigma_t\sqrt{h} - 1.5 c\)

**稳健性**
- 按 root 分别的条件均值（符号一致性检验）
- 按 phase 分别的条件均值
- 按月份分别的条件均值（检查是否集中于某一个月）
- 按 `magnitude` 三分位的条件均值（**应该单调**：强触发的效应应强于弱触发。若不单调，说明 magnitude 定义有问题，或整体是噪音）

**多空分解（宪章补充要求）**
多头触发与空头触发**必须分开报告，禁止合并成"绝对收益"**。股指有三个稳健的不对称：
- 负偏与跳跃的方向性（大跳跃绝大多数向下）
- \(\mathrm{Corr}(r_t, \Delta\sigma_t) < 0\)：做空股指时，赢的时候波动扩张（波动定标会自动缩仓，吃不满）、输的时候波动收缩（仓位放大）。**同等信号强度下，做空的实际夏普系统性低于做多**
- 均值回归的方向不对称：股指的"买跌"长期有效，"卖涨"历史表现明显更差

因此：允许多空使用不同阈值、不同 horizon、不同仓位缩放；空头信号在同等显著性下应给更低权重。

> **迁移提示（写入报告，为后续商品/加密准备）**：这个不对称在迁移时会翻转。能源/农产品的供给冲击使跳跃**向上**、分布右偏；黄金的相关性符号随通胀/增长 regime 切换；加密的波动-收益相关符号不稳定且上涨也伴随波动扩张。**假设对称是偷懒，假设股指的不对称能迁移同样是偷懒。**

**显著性**
- 原始 t 统计量（仅作参考）
- Newey-West 修正 t 统计量（lag \(= h\)）
- **Stationary bootstrap t 统计量**（块长期望 \(= 5h\)）—— 以此为准
- 随机时点对照组分位（见 7.2）
- 跨品种 LOI 结果（见 7.3）

### 7.2 随机形态对照组（`stats/nulls.py`）—— 必建的基础设施

**这是本项目性价比最高的单个验证工具。**

方法：生成 \(B = 2000\) 个"假检测器"，每个具有与真实检测器**完全相同的触发次数、按 phase 的触发分布、多空比例**，但触发时点在同一 phase 内随机抽取。计算每个假检测器的条件均值/夏普，得到零分布。

关键设计：
- **必须匹配 phase 分布**。否则零分布会混入日内季节性效应，导致"任何集中在开盘的检测器都显著"
- **必须匹配触发簇集结构**。若真实检测器的触发在时间上簇集（同一天多次），随机版本也要簇集（用 block 抽样触发日，日内再随机时点）
- 同时匹配多空比例（对付股指的方向不对称）

为什么它比理论 t 检验可靠：它自动处理了重叠窗口、序列自相关、非正态性、日内季节性残留、以及触发簇集 —— 这五个问题的任何一个都足以让理论 t 值虚高 2 倍以上。

**门禁**：真实检测器必须位于零分布的 \(\ge 92.5\) 分位（单边）。

### 7.3 跨品种留一验证（LOI）—— 最有价值的样本外

在 ES/NQ/HSI 上确定全部参数，在 RTY 上不做任何调整地测试；轮换。

**为什么它比时间分割强**：时间分割的两段共享同一个宏观 regime（本样本只有 6 个月，很可能只有一到两个 regime），"样本外"的独立性是虚假的；而品种之间虽然相关，但它们的微观结构、参与者构成、成本结构确实不同，验证是真的。

**报告**：LOI 下的条件均值 vs 全样本条件均值的比值。健康的形态应保持 \(\ge 0.5\)。

### 7.4 参数曲面与稳定性（`stats/stability.py`）

**核心方法论断言**：半年数据下做 train/test 分割，测试集只有 1–2 个月，其夏普估计标准误 \(\approx 1/\sqrt{1/6} \approx 2.4\) —— **样本外测试本身就是噪音，通过与否近似抛硬币**。因此不要把希望寄托在 OOS 上。

更可靠的抗过拟合工具是**参数曲面的平滑性**：真实效应会在参数的连续邻域内平滑变化（真实的市场机制不会对"20 根 bar"和"22 根 bar"有本质区别）；孤峰必然是拟合的。

实现：
1. 对每个数值参数做网格扫描（每个网格点计入试验计数 \(K\)）
2. 画 1D 曲线与 2D 热力图（对最重要的两个参数）
3. 计算稳定性：
   \[
   \mathrm{Stab} = \frac{\mathrm{median}\{\,\text{表现}(p') : p' \in \mathcal{N}(p^{\*})\,\}}{\text{表现}(p^{\*})}
   \]
   其中 \(\mathcal{N}(p^{\*})\) 为最优点的相邻网格点（每维 ±1）
4. **最终参数取高原中心，不取峰值点。**在报告中明确写出"峰值在 X，采用 Y（高原中心），峰值/采用值的表现差 Z%"

**门禁**：\(\mathrm{Stab} \ge 0.70\)。

这个方法优于 OOS 的地方在于：它使用了**全部样本**做诊断，而不是把 1/3 的宝贵数据献祭掉；且它检验的是一个更本质的性质 —— 效应对参数的连续依赖性。

### 7.5 多重检验账本与 DSR

`RESEARCH_LOG.md` 累计的 \(K\)（含所有被放弃的尝试）用于计算折算后的门槛：

\[
SR_0 = \mathrm{se}(\widehat{SR})\cdot\Big[(1-\gamma)\,\Phi^{-1}\!\big(1-\tfrac{1}{K}\big) + \gamma\,\Phi^{-1}\!\big(1-\tfrac{1}{Ke}\big)\Big]
\]

以及 Deflated Sharpe Ratio：

\[
\widehat{DSR} = \Phi\!\left(\frac{\big(\widehat{SR} - SR_0\big)\sqrt{T-1}}{\sqrt{1 - \gamma_3\widehat{SR} + \frac{\gamma_4 - 1}{4}\widehat{SR}^{2}}}\right)
\]

（\(\gamma_3, \gamma_4\) 为策略收益的偏度与峰度。）

参考量级（\(\mathrm{se} \approx 1.2\)）：\(K=20 \Rightarrow SR_0 \approx 2.6\)；\(K=100 \Rightarrow SR_0 \approx 3.3\)；\(K=1000 \Rightarrow SR_0 \approx 4.0\)。

> **必须在最终报告首页写出 \(K\)、\(SR_0\)、\(\widehat{DSR}\)。**"我回测出夏普 2.5"在没有说明试了多少个变体之前是零信息量的。

## 8. 状态条件化与分层收缩（Stage 4）

### 8.1 为什么必须收缩

Regime 引入的是**参数的乘法爆炸**，而样本是**除法收缩**：\(K\) 个状态、\(M\) 个因子 → 参数 \(K \times M\)，每状态样本 \(n/K\)，每参数的信噪预算下降 \(K^2\) 倍。

具体到本项目：池化后有效下注约 400–600 次。切 3 个状态 → 每状态约 150–200；再切多空 → 每格 75–100。在 100 次观测上估条件均值，标准误 \(0.1\sigma\)，而目标效应量正好是 \(0.1\sigma\) 量级。**信噪比 = 1。**

**这就是为什么大量 regime-switching 策略样本内漂亮、样本外崩溃 —— 不是思想错了，是实现方式吃掉了全部统计预算。**

### 8.2 复合形态元组与二阶截断

定义形态为元组：

\[
\mathcal{P}_t = \big(S_t,\; E_t,\; V_t,\; Q_t,\; L_t,\; \tau_t\big)
\]

（结构、效率、波动、量能、位置、时段）。每维 2–3 档 → 数百到上千格。**逐格估计必然失败，必须做分层分解**：

\[
\hat\mu_{\text{cell}} = \underbrace{\mu_0}_{\text{全局}} + \sum_{d}\underbrace{\alpha_d}_{\text{主效应}} + \sum_{d<d'}\underbrace{\beta_{dd'}}_{\text{二阶交互}}
\]

**三阶及以上强制为零。**参数量从 1000+ 降到 \(1 + 12 + 60 \approx 73\)，且每个参数有大量样本支撑。这是"结构上复杂、参数上受约束"的具体落地。

### 8.3 经验贝叶斯收缩

\[
\hat\mu_k^{\text{sh}} = \frac{n_k/\sigma^{2}}{n_k/\sigma^{2} + 1/\tau^{2}}\,\bar r_k \;+\; \frac{1/\tau^{2}}{n_k/\sigma^{2} + 1/\tau^{2}}\,\mu_0
\]

其中 \(\tau^2\) 为格间真实效应方差，用矩估计：

\[
\hat\tau^{2} = \max\Big(\mathrm{Var}_k(\bar r_k) - \mathbb{E}_k\big[\sigma^{2}/n_k\big],\ 0\Big)
\]

> **关键纪律**：若 \(\hat\tau^2 = 0\)，数据在告诉你"格子之间没有真实差异"。**老老实实接受这个结论，写入报告，退回无条件版本。**不要换个分箱方式再试一次（那会让 \(K\) 暴涨且结果不可信）。在这个游戏里，能听懂并接受否定性证据的人，长期收益率远高于总能"找到点什么"的人。

### 8.4 跨品种层次

\[
\mu_{ik} = \mu_k + \delta_{ik},\qquad \delta_{ik} \sim N(0, \tau_2^{2})
\]

先估池化的 \(\mu_k\)，再让每品种偏离 \(\delta_{ik}\) 受强收缩。**\(\tau_2^2\) 默认设得很小 —— 默认假设是"形态在所有品种上效应相同"，除非数据有极强证据反对。**

`confidence` 字段由收缩后的后验精度填充：

\[
\text{confidence} = \frac{n_k/\sigma^2}{n_k/\sigma^2 + 1/\tau^2}
\]

这样样本少的格子自动输出低置信度，融合层无需知道检测器内部细节就能正确加权。

### 8.5 G4 验收

画「条件收益 vs gate_score 分位」曲线（10 分位）。要求：
- isotonic 拟合 \(R^2 \ge 0.6\)
- 相邻分位跳变 < 总幅度的 40%
- 单调方向与 `HYPOTHESES.md` 中的先验一致

**锯齿状 = 噪音，退回无条件版本并记录。**
