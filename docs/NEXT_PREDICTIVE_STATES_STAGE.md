# 下一大阶段：受几何约束的预测状态发现

冻结设计：2026-09-29，先于本阶段验证/测试结果。依据[形态原型下阶段分析思考](形态原型%20下阶段分析思考.md)，本阶段改变的是**原型出生规则**。特征仍由可解释量价构造，原型的中心、数量和方向不由人工机制指定。旧八种语义种子只作历史研究参照。

## 可证伪的问题

1. 当前多尺度截面、4h 两端、4h 有序中间节点三种表示，在同一预测目标下谁提供额外信息？若中间节点不增加独立时间块的分布预测质量，路径容量不被支持。
2. 历史几何产生的局部区域能否在未来收益**分布**上改善预测？允许某个状态没有方向优势，也允许远离的历史区域在预测层共享分布估计。
3. 用开发期时间块决定局部拆分，是否优于纯几何划分？若结果只在拆分选择块改善而在后期失效，弱监督结构不成立。
4. 与同输入、同目标的直接预测模型相比，局部状态是否提供预测增益、可解释的支持范围或稳定的异质性？没有增益时明确报告阴性。

## 时间职责

`2023-01—2024-12` 拟合候选几何与初始结果分布；`2025-01—2025-06` 在发现区内部比较分辨率/拆分；`2025-07—2026-01` 作用户指定验证并选一个冻结方案；`2026-02—2026-09-24` 作最终测试。24h 标签必须在所属区间终点前完整可知。用户本轮明确授权这一新切分，替代旧文档把整个 2026 冻结的安排。2025 的旧结果曾被看过，故 2025-07—2026-01 不是历史上从未触碰的数据；本阶段的**新算法**在读其结果前冻结，测试区也不许回头选择方法。

## 预先确定的表示、目标与模型族

输入用七组注册字段（非时间组各四个，时间组四个），共 28 个当前字段；非时间六组各两个字段增加 4h 前节点。X0 为当前 28 维，X1 加 4h 前 12 维成为 40 维，X2 再加 1h/2h/3h 三个中间节点及峰谷先后位置，成为 100 维。各原始字段仍由项目已有 5m/15m 特征实现定义；路径滞后严格按同币已完成 15m 快照。训练期为每币各字段拟合 101 结点并列值中位秩分位，测试仅变换；组内根据字段数缩放，使一个组不能仅因字段多而统治距离。另做混合币种分位消融。完整字段、单位、方向、缺失、冗余与可用时间见本阶段字段登记表。

4h/24h 结果均从下一 5m 开盘到未来相应开盘计算；按信号时点已知的过去 RV 标准化并映到五个固定收益档。另预测未来 4h RV 是否高于当前 RV 对应的 4h 基准。评分为三个任务的平均对数损失，分别报告 4h/24h 收益分布与高波动概率的损失、校准和原始 bp 条件均值。收益档边界、实现与目标权重都写在配置中，测试前不按结果调节。

主候选先用受组权约束的 k-means 建 8 个父区域，每个区域可按同一输入几何二分。拆分只在发现区内部的后段改善目标分布对数损失、两个子区域都有日期/事件支持时保留，最多额外 8 片。类结果用父区域与币种背景作 Dirichlet 收缩。中心是拟合量，同时保存每区一条**真实 medoid**供检查；分类距离仍到拟合中心，并用训练距离半径界定支持。另立一条真实近邻图候选：以历史真样本建图、形成社区并按最近邻支持拒绝。新点不需 99%+ 的高相似事件阈值，默认按区域预测，超出训练 90% 半径则回退币种背景并标记拒绝。对方向的判断是结果层的输出，几何阶段不命名多空。

内部对照：仅截面、两端路径、中间路径；纯几何八区域、按预测增益拆分；币种与混合分位；同字段的 LightGBM 三目标直接概率预测。LightGBM 与原型使用同一标签和测试时刻。所有方案及失败结果同表保存；最终方案只能按验证期的预定综合对数损失与覆盖规则选择，不凭测试收益选胜者。本阶段止于状态及未来条件分布研究；仓位、换手、费用与买入持有投资比较留给后续信号阶段。

## 产物与限制

保存字段登记、切分及版本清单、完整方案评分、原型真实 medoid 与父子关系、局部结果分布/分币分期卡、拒绝覆盖、状态转移、测试预测记录、图和综合报告。原始 parquet 只读，新产物在 `reports/crypto/predictive_states_v1/`。若直接模型更好，或原型只预测共同市场波动而不预测币种特有收益，照实报告。任何概率分离仍是预测性关系，不是因果效应或交易认证。
